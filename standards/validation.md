# 验证标准

每次验证说明对象、版本或日期、验证者、方法及证据位置。结果使用：

| 结果 | 含义 |
| --- | --- |
| PASS | 已执行且证据支持预期 |
| FAIL | 已执行且发现差异 |
| UNKNOWN | 证据或执行条件待补齐 |
| N/A | 当前范围不适用，附具体理由 |

需求检查至少覆盖范围、主流程、异常、边界、状态、字段、来源、API 映射、权限、兼容性和验收条件。每行记录实际检查对象、方法、结果、证据以及问题动作。

问题记录编号、严重性、影响、负责人和复验结果。完成条件由任务约定与验证证据共同决定；自检、业务评审、实施验证和最终验收分别记录。

涉及脚本时实际运行并检查输出，覆盖核心行为和失败路径。跨设备、外部系统等依赖验证记录实际环境；静态模拟结果注明验证范围。
