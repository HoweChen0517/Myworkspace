# PRD 标准

PRD 包含背景与目标、范围、角色和触发、主流程、异常与边界、业务规则、数据与接口、权限、兼容、依赖和验收条件。简单需求可合并章节，适用性以业务内容为准。

- 每条需求使用稳定编号 `FR-001`，描述角色、触发条件、行为和可观察结果。
- 范围包含本期交付及后续范围；数字、字段、枚举和时间规则具有明确口径。
- 每个字段写明来源、类型、必填、默认、校验、展示及空值处理；接口详情通过链接引用设计。
- 明确正常、失败、重试、重复操作、权限不足、历史数据和边界场景。
- 验收使用 `AC-001` 编号和 Given / When / Then，关联需求编号与验证证据。
- 未知业务事实进入 Open Questions，并说明确认人、影响和下一步。

交付检查：brief 范围、有效决策、design 和 PRD 一致；验收条件可执行且覆盖核心场景。评审状态记录于 status 和 validation。
