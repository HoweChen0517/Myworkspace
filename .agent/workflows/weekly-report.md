# 周报

## Trigger
指定周期的进度汇总或阶段总结。

## Input
日期范围、受众、项目清单。

## Required Context
相关项目 status、周期内 changelog / Git 历史、任务与产物证据。

## Steps
1. 明确周期和纳入范围。
2. 按证据区分已完成、进行中、阻塞和需决策事项。
3. 汇总成果、业务影响、风险与下周期计划，引用具体产物。
4. 核对日期、计数、状态和受众可见范围。

## Output
项目 `artifacts/weekly-YYYY-MM-DD.md`。

## Validation
每项成果具有产物或验收记录；数据口径和覆盖期明确；未知影响保留为待验证。

## Persistence
保存报告并执行公共会话结束协议；需要协作副本时记录来源版本与导出位置。
