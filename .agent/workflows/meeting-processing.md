# 会议材料处理

## Trigger
会议纪要、聊天、反馈或其他 inbox 输入待整理。

## Input
已确认数据分级的原始材料、来源、日期和参与人。

## Required Context
[Inbox 说明](../../inbox/README.md)、涉及项目的 status / handoff，按需读取当前需求。

## Steps
1. 确认归属项目与需求，待确定项记录为 Open Question。
2. 将原始发言提炼为事实、建议、已确认决策、任务和待确认项，并保留来源定位。
3. 核对与既有产物的差异；冲突项记录双方来源与确认动作。
4. 更新对应产物，任务包含负责人和完成条件。
5. 将原始材料归入适当的 references 或批准的私有位置，更新处理登记与链接。

## Output
摘要、任务、决策或待确认项及原始材料引用。

## Validation
结论能定位原文；负责人和日期保留原始确定程度；建议与正式决策分别标记。

## Persistence
更新 inbox 处理登记和对象状态，执行公共会话结束协议。
