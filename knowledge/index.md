# Knowledge Index

知识条目保存可复用事实，包含来源、适用系统或版本、核验日期、维护人和分级。下表是分类导航；具体事实按条目登记，当前业务知识等待真实资料输入。

| 分类 | 用途 |
| --- | --- |
| [company](company/README.md) | 可同步的组织背景 |
| [systems](systems/README.md) | 系统边界、模块与流程 |
| [business](business/README.md) | 业务规则与口径 |
| [database](database/README.md) | 数据库概念与批准的 Schema 引用 |
| [api](api/README.md) | 接口契约与字段映射引用 |
| [glossary](glossary/README.md) | 术语和统一释义 |
| [portable](portable/README.md) | 通用且可同步的知识 |

公司原始材料放在本地 `company-private/` 或批准的独立仓库，该本地目录由 Git 忽略。在另一设备恢复时，根据授权取得对应资料；待取得的资料写入当前对象的依赖。公共索引登记内容同样需要符合分级要求。
